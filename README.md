# Lakshmi Electricals Website

Website for Lakshmi Electricals, a Class 'A' electrical contractor based in Kozhikode, Kerala.

**Live site:** [lakshmi-electricals-c98o.onrender.com](lakshmi-electricals-c98o.onrender.com)

## Features
- Overview of the company
- Services list with filters
- Quote request form
- Contact details with phone and address
- Works on phone and laptop

## Built with
- React
- Vite
- Tailwind CSS

## Run on your computer
1. Clone the repo
2. Run `npm install --legacy-peer-deps`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Deploy
Hosted as a static site on Render.
- Build command: `npm install && npm run build`
- Publish directory: `dist`

## Update content
All text is in `src/App.tsx`.
- `INFO` has the address and phone numbers
- `SERVICES` has the services list
